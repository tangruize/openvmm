# Verus concurrency tutorial (copy)

A copy of the Verus concurrency tutorial by Shan Lu (draft), online at
https://people.cs.uchicago.edu/~shanlu/verus-concurrency/. Kept here so
that it can be read without network access. Open `index.html`.

The chapters in its table of contents:

| Chapter | File | Topic |
|---|---|---|
| 1 | `ch23_threads_no_sharing.html` | threads that share nothing |
| 2 | `ch24_concurrent_updates.html` | atomic invariants |
| 2.1 | `ch24_1_atomics.html` | atomic invariants for atomic variables |
| 2.2 | `ch24_2_locks.html` | atomic invariants for lock-protected data (lock invariants) |
| 3 | `ch25_ghost_resources.html` | ghost resources (fractional ghosts) |

The other chapter files here (`ch24_atomics_invariants.html`,
`ch25_locks.html`, `ch26_*`, `ch27_*`) are older drafts, not in the table
of contents. The `my_*.rs` files are the examples.
